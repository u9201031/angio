## 決策式規則（只列 ≥2 例支持的）
- **Aneurysm**
  - 若用 **FD Shield**，微導管常用 **Phenom 27**（9/11），guide 常用 Navien（8/11），常搭 Shuttle 長鞘（5/11）。例外：P034 報告只寫到 8F sheath，沒寫微導管。
  - 若用 **FD Vantage**，微導管常用 **Phenom 21**（4/7），guide 常用 Navien（6/7）。例外：P067 用 Headway 21。
  - 若用 **FD p64**，微導管常用 **Headway 21**（3/7）；其餘 4 例 OCR 沒抓到微導管。
  - 若是 **ICA ophthalmic / SHA** 段，最常見是 Navien + Phenom 27 + FD Shield（ophthalmic 4/10，SHA 2/2）。其他 ophthalmic 病例用 p64（P037、P046）、Derivo（P040）、Vantage（P065）、Elite⚠️（P072），也有單純 coil（P056）。
  - 若是 **ICA PComA**，FD Shield 3/8、p64 2/8，coiling 2/8（P045、P058）。
  - 若是 **AComA / pericallosal**，用 FD Vantage 2/2（P035、P067）。
  - 若是 **MCA**，器材分散：p64 2/8、Pipeline、Silk、Vantage 各 1，另有 stent-assisted coiling（P063，Neuroform/Atlas + Headway 17）。目前歸不出單一規則。
  - 若做 **coiling**，微導管常見 SL-10（3/9）或 Headway 17（2 例：P058、P063）。
  - 止血：AngioSeal 16/38，其餘沒有記載。
- **Dural AVF**
  - 若是 **cavernous dAVF / CCF**，經靜脈 3/5（P003、P004、P006），用 coils 4/5。例外：P005 是 lateral cavernous dAVF，經動脈 Onyx；P009 是 Barrow A CCF，經動脈 coils，⚠️ OCR 另抓到 Shield。
  - 若是 **Galen type**，用 Onyx 3/3（P001、P007、P008，同一病人分期），P001 另加 NBCA/Lipiodol。
  - 若是 **tentorial / T-S sinus**，coils 3/4、Onyx 2/4，Onyx 常配 Apollo 或 Echelon（P011、P013 雙導管）。
  - 若用 **Onyx**，微導管常用 **Apollo**（3/6）。
- **AVM**：n=5，器材抽取不完整，**無法歸納規則**。顏面 AVM 用 coils 2/3（P019 NBCA、P020 Onyx）。
- **Tumor**
  - 若是 **retinoblastoma SOAI**：Phenom Plus 中間導管 7/7，Melphalan + Topotecan 7/7（Carboplatin 6/7），以 manual compression 止血 7/7。微導管用 Headway 17（4/7）或 Marathon（2/7）；P021 用 Echelon。
  - 若是 **頭頸部惡性腫瘤或轉移，以及 glomus / paraganglioma**：以 NBCA 為主 4/4，頭頸癌加 Lipiodol 2/2。
  - 例外：P031 腳部 hemangioma 用 ethanol + Scepter balloon。

## 限制
- 器材是用關鍵字從 OCR 文字抓出來的。報告沒寫、或 OCR 糊掉，就會漏掉（「—」）。
- 尺寸只在部分報告出現，例如 FD 4.5×20mm（P057）、Vantage 3.25×16/20mm。
- 「Phenom」沒寫 21 或 27 時只記 Phenom。Elite（P072）與 P009 的 Shield 為 ⚠️ OCR 不確定。
