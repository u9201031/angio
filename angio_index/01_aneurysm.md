## 教學筆記 / Pearls

- **Giant aneurysm**：顯影劑 inflow 多就塞滿 coil；看起來偏 thrombotic 就直接放 FD。（#angio 3/31）
- **Pcom infundibulum ≥3mm 當 aneurysm 治療**；注意 duplication 與 fenestration 的區別。（#angio 2025/06/23）
- **A1 aneurysm SAC**：ICA→A1 的 stent 會蓋過 M1 ostium（jailed）；機械性阻塞機會低，但有 thromboembolic MCA stroke 風險 → DAPT 要足、coil 要塞緊；也可考慮 Y-stenting。（#angio 2025/09/01）
- **FD sizing / braid angle**：undersize → braid angle↑、metal coverage↓、flow diversion↓；oversize → coverage↑ 但 perforator 梗塞與 malapposition 風險↑。以 distal（最小）管徑為準，增加 coverage 用 overlap 比 oversize 安全。BA / perforator 多的區域避免過度 oversize。（Flow diverter 2026/04/13）
- **兩支 FD**：先 distal 再 proximal，overlap 5–10mm；posterior circulation 盡量避免雙層。（Flow diverter）
- **Perisplenial vs posterior choroidal**：「Deep = choroidal（不能動），Surface = perisplenial（比較安全）」——FD 不要蓋到 posterior choroidal（會 thalamic infarct）。（Flow diverter）
- **FD torsion / 擴張不全**：還沒脫離 → resheath、消掉 torque 再重新釋放；已脫離 → 用 .014 微導線確認從 central lumen recross → Dotter → undersized balloon 慢慢擴張 → 不行就 stent-in-stent（Atlas/Enterprise）；全程 ACT 250–300 + tirofiban。（#angio 2026/09/07）
- FD 放完有 fish mouth 可以做 angioplasty：先用軟的 Scepter 撐，再用 Gateway。Scepter 直接用 syringe 打；Gateway 才需要壓力槍。FD 放完若要 PTA，需要 300cm exchange wire。（TO3KIBA；BA FD note）
- **Atlas 1.7Fr**：open cell 但網孔密，micro wire 穿不過；複雜 aneurysm 用 waffle-cone；SL-10 斷掉可用 snare 取出。（ICAD wingspan）
- **M2 微導線穿孔**：停止往前推、wire 留在原位（可能正在 tamponade），roadmap 確認 extravasation，做 temporary coiling，必要時 reverse heparin。（#angio 2025/12/15）
- p64 用 Phenom 21 放；FD Vantage 用 Phenom 21。
