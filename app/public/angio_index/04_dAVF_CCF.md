## 教學筆記 / Pearls

- **Spontaneous high-flow CCF** 要想到 cavernous ICA aneurysm 破裂。即使是 direct CCF 也要準備 trans-A 和 trans-V，先從 A 塞，塞不好再從 V。（#angio 2026/01/05 ⚠️ 標題日期與建立日 2026-09-03 不符）
- **「Direct CCF + trans-arterial = balloon first, coil later」**：balloon 放在 cavernous ICA inflate 當安全鎖 → microcatheter 穿過 fistula → 先放 framing coil → 補 coil → deflate → 確認 ICA 通暢。高流量 traumatic CCF、開口大、fistula 直通 ICA 主流時，不要不打 balloon 直接放 coil。
- IJV 穿刺：短 sheath + 5F 或 4F H1，先把脖子伸展再穿刺。
- Indirect CCF：看 facial vein 的位置；器材 Shuttle 6F / Navien 58 / Phenom 21。（indirect CCF 2025/08/18）
- dAVF：Target coil 比較硬，跟 Axium 比較好推；Onyx 可以等 2–3 分鐘 solidify 再打。**Marathon（ID 0.013"）不能放 coil**；同時要 coil + Onyx 時開 Echelon-10（0.017"，相容 DMSO）。SL-10 不能打 Onyx。（TO3KIBA）
- Onyx vs NBCA：safe margin 太短選 NBCA（Onyx 容易 reflux）。（#angio 08/31）NBCA：Envoy 6F，先打 D5W/D10W 再打 NBCA（#angio 2025/01/13）；NBCA 20%（#angio 2025/08/04）。打 DMSO 有時會 bradycardia。（#angio 2025/02/10）
- APA 栓塞的危險 anastomosis：APA hypoglossal branch ↔ MHT dorsal meningeal artery → reflux 可能進 cavernous ICA；也可能 CN XII palsy。（#angio 2026/09/07）
- Dural AVF 分類（Cognard / Borden）。（#angio 2025/03/03）
